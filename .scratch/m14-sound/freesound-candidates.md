# Freesound and OpenGameArt candidates for M14 (ticket 01)

Every search below ran with Freesound's **Creative Commons 0** licence filter
(OpenGameArt: CC0 only), 2026-09-17. Before downloading, check the licence on
the sound's own page still says "Creative Commons 0".

**How to use this list:** listen on the page, tick what fits, and download the
**original** (Freesound needs a login) into `assets/audio/freesound/`, named
`<id>-<short-name>.<ext>`. I then trim, loop, normalise, encode `.ogg` and
credit each one (ticket 01).
