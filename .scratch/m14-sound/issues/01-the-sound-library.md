## How it behaves after

- Raw downloads live under `assets/audio/kenney/<pack>/` and
  `assets/audio/freesound/<id>-<slug>.<ext>`, untouched.
- Runtime files live in `apps/client/public/sounds/<group>/<slot>_<n>.ogg`.
  Groups are `character`, `segment`, `environment`, `match`, `music`, `ui`.
  Variants are numbered `_0…_4`.
- `apps/client/public/sounds/CREDITS.md` has one line per shipped file: slot
  file → source URL, author, licence (CC0), and the date checked.
- A test fails if a file under `public/sounds/` has no line in `CREDITS.md`, or
  a line names a missing file.

## As built

- **One table, one script.** `scripts/sound-library.ts` lists each output: its source under
  `assets/audio/`, how it's processed, and its origin (title, author, licence, URL).
  `pnpm build:sounds` wipes `public/sounds/`, rebuilds it and writes `CREDITS.md` from the same
  rows, so a file can't ship without a credit. It takes about 30 s.
- **Processing:**
  - `copy`: Kenney Ogg Vorbis as-is.
  - `oneshot`: silence trimmed at both ends, 5 ms fade in / 30 ms fade out, peak-normalised to
    −1 dBFS, mono Ogg Opus 64 kbps.
  - `loop`: the tail crossfades (equal-power, `qsin`) into the head, then a static gain to the
    row's LUFS, capped at a −1 dBFS peak. Measured: the wrap sample step is within the typical
    step (e.g. wind 11 vs 26.7). A limiter was tried first and broke the seams: its look-ahead
    delays the signal.
  - `music`: static gain to −16 LUFS (peak-capped), stereo Ogg Opus 96 kbps.
- **Size:** about 13 MB, of which music is 11 MB (8 tracks).
- **Slots:**
  - `character/`: footstep, land, land_heavy, jump, dash, slide_loop, spring, fall, respawn,
    hit_swing, hit_land, hit_land_heavy, grab, knockdown, knockdown_hard, getup;
  - `surface/`: mud ×4, ice ×5 (cut at gaps found with `silencedetect`), bounce;
  - `segment/`: swing ×5, swing_heavy ×2, spin_pass ×2, slide_stop ×5, fan_loop, belt_loop,
    slide_rumble_loop (stand-in);
  - `environment/`: wind_day_loop, wind_night_loop, birds_loop, crickets_loop;
  - `match/`: count_3/2/1, go, hurry_up, time_over, final_round, you_win, congratulations,
    checkpoint, qualified, round_end, results, results_win (male announcer);
  - `ui/`: click ×5, confirm ×4, back ×4, toggle ×4, tick ×3;
  - `music/`: lobby ×3, round ×5.
- **Not shipped:** "Slow helicopter #3b" (Timbre, CC-BY-NC) stays in `assets/audio/freesound/`
  but no row uses it. Delete it if the raw folder is ever published.
