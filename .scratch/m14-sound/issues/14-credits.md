# 14 — Credits: every CC-BY author, in the game

**What to build:** a Credits screen that names every sound author whose licence requires it,
generated from `apps/client/public/sounds/CREDITS.md`. **ADR 0087** (amendment).

**Decided (user, 2026-09-17):** CC-BY files are allowed, with attribution. NC files never are.

**Blocked by:** 01

**Status:** done on tests (2026-09-17). Looking at the Screen is the user's check.

## How it behaves after

- A CREDITS entry on the main menu (and in Settings) opens a Screen listing:
  - every CC-BY sound: title, author, licence, source link;
  - thanks to Kenney (CC0, credit not required but given);
  - "Music generated by the game's author."
- The list is built from `CREDITS.md` at build time, so a new CC-BY file can never ship uncredited.
- A test fails if a CC-BY line in `CREDITS.md` is missing a title, author, licence or URL.

- [x] Tests: CC-BY entries render with author and licence, and the parser rejects incomplete lines

## As built

- **Parser (`audio/credits.ts`):** ticket 01's `parseSoundCredits` now also refuses a CC-BY row
  without its source link, alongside unreadable rows, missing cells and unknown licences such as NC.
- **`creditsView`** groups the credits for reading:
  - one line per CC-BY work (Wind.wav serves two files and is named once), with author, licence
    and link;
  - CC0 authors thanked once each, with their works and links;
  - the music tools (Suno, Stable Audio) taken from the Generated rows.
- **The Screen:**
  - `screens/Credits.tsx`, in the Scoreboard's vocabulary (Stage, Panel, JellyButton).
  - Sections: SOUND (attribution), WITH THANKS · CC0, and MUSIC ("Music generated by the game's
    author with Stable Audio and Suno.").
  - Links open in a new tab.
  - The list stacks to one column on a phone.
- **Route:** `screens/CreditsRoute.tsx` at `/credits`.
  - It reads `public/sounds/CREDITS.md` with `?raw`, so the list is in the build.
  - A production `vite build` bundles it into the menu chunk, which stays free of three.js.
  - BACK returns wherever the Player came from.
- **Entries:** CREDITS in the main menu's nav, and a CREDITS button beside RESET in Settings.
- **The component library:** the ticket said `packages/ui`, but the Screens around it (Scoreboard,
  Settings) are built from the client's own `ui/` kit, so Credits is too. Reconciling the two kits is
  M9 ticket 03's decision.
- **Tests:**
  - `audio/credits.test.ts`: the link rule, grouping, and every shipped CC-BY file present in the
    view.
  - `screens/Credits.test.tsx`: attribution rows with link, author and licence; the Kenney thanks;
    the music line; BACK; and `/credits` reached from another route and back.
