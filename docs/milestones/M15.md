# M15 — What the Screens show is real

## Done when

> **Every value a Player sees on a Screen or the HUD comes from the Lobby socket, the API or the
> Account. Nothing is a mock default, a hash of an id or a caption left over from the design. Every
> button the design shows does what it says: Leaderboards, SURVIVAL, emotes, the pause menu,
> parties, voice chat, drafts and a real queue included.**

The user's ask on 2026-09-19. The audit is `docs/research/ui-mock-audit-2026-09.md`, and the
definitions settled in three question rounds the same day are **ADR 0110**.

## Order

1. **Truth from what exists** (01–08). Bugs and wiring. No new system and no open question, except
   the betting window in 03.
2. **New tracking** (09). Survival time and Struggles won, per participant.
3. **New systems** (10–18). Each ticket that says "design open" is settled with the user before it
   is built, and gets its own ADR.

## Not in this milestone

Password reset, the shop, the Ragdoll overlay and the Elimination card (ADR 0110, "Not built now").

## Tickets

`.scratch/m15-real-screens/issues/`. Tickets close on tests and typecheck. Visual and live checks
are the user's.
