# M1 — Local physics playground

## Done when

> **"It's fun to walk, jump, bump, and fall."**

If after 30 minutes of playing it ourselves we're happy just shoving the
Character off a ledge, M1 succeeded — that's the core gameplay loop.

## Scope

Single-player. No multiplayer, no server, no lobby, no accounts, no backend.
But: fixed 30 Hz simulation with a render-interpolation layer from day one (ADR 0004).

## Checklist

### Character & control
- [ ] One kinematic capsule Character
- [ ] WASD movement (relative to movement/camera per Q12: dash impulse follows movement direction, not camera)
- [ ] Jump — variable height (hold = higher), coyote time ~100 ms, **no double jump**
- [ ] Dash — ground only, cooldown ~1 s, fixed impulse in movement direction
- [ ] Dash into a wall/edge → transition to Ragdoll
- [ ] Procedural `Wobble` on the visual mesh while `Controlled` (cosmetic, no collision effect)

### Character state machine (ADR 0006)
- [ ] `Controlled → Stagger` on minor Impact; auto-recovers
- [ ] `Controlled → Ragdoll` on hard Impact / Fall / dash-into-wall
- [ ] Short `Ragdoll` with real articulated physics
- [ ] `Ragdoll → GettingUp` blend back to standing
- [ ] `GettingUp → Controlled`
- [ ] Impact Reactions visible (flinch / knockdown)

### World
- [ ] Basic platform geometry
- [ ] An edge you can walk / be knocked off → `Fall` below a kill-plane
- [ ] Checkpoint + Respawn with a short time penalty
- [ ] One Spinner (rotating Obstacle bar)
- [ ] A few simple dynamic physics props to bump into and knock around

### Camera
- [ ] Third-person spring-arm follow
- [ ] Camera collision (shorten the arm against geometry)
- [ ] Optional mouse orbit, mostly-fixed pitch

### Engine plumbing
- [ ] Fixed 30 Hz simulation step, living in `packages/shared`
- [ ] Render loop at display refresh rate, interpolating between sim states
- [ ] Tuning constants (jump, dash, fall threshold, penalties) as named constants in `packages/shared`

## Explicitly NOT in M1
Multiplayer · server · lobby · accounts · procedural Segments · Modules ·
Rounds · Qualification · Power-ups · Item Boxes · Grab · Betting · level themes.
