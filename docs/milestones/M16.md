# M16 — Traps that act

## Done when

> **A Track author places a sweeper, a trap door, a fragile floor, a shooter,
> a belt and a punching glove from the Assets tab, sets their numbers in the
> inspector, and every Player in the Round sees the same arms swing, the same
> hole open, the same tile break, the same ball fly, the same belt carry and
> the same glove land.**

Six authored GLBs arrived on 2026-09-21 (four at first, two while the first
four were being built). Every Asset the game has today is
**geometry**: it holds you up, it blocks you, at most it moves as one rigid
piece on a clock (ADR 0061). These four are the first that *do something* —
and each of them asks the engine for something it has never had.

## Design

Settled with the user in three question rounds on 2026-09-21. Recorded as
**ADR 0116** (an Asset can be more than one body), **0117** (the trap door),
**0118** (the fragile floor), **0119** (the shooter), **0120** (the belt) and
**0121** (the punching glove). In short:

- **The author places one thing.** An Asset def may declare Parts — `still`,
  `moving`, `gated` — and one placed Segment resolves into one body per Part.
  The stored Track, the builder's placement, publish validation and the MCP
  tools learn nothing. The seam is `resolveTrack`'s `segmentBody`.
- **None of the four loads as exported.** The shared reader refuses a meshed
  node with no `role`; every Asset in the game comes through a convert script
  and these have none. `scripts/convert-df.ts` is the first ticket.
- **The clips are reference, never played.** They are read to derive the
  defs' default numbers (the rotor's 1.246 rad/s, the doors' 88° and 0.75 s
  hold, the shooter's ±35°), which then live where an author can move them.
- **A moving Part collides as fitted box proxies** (ADR 0065), not trimeshes.
  Hand-authored proxies only if a fitted box visibly lies — the user's call.
- **Sweeper: nothing new.** Its rotor is a moving Part on the M11 Impact
  rule; speed and direction are the author's.
- **A seventh GLB, and a Motion that speeds up** (2026-09-23). The three-arm
  sweeper has three rotors at three heights, each at its own rate and
  direction, so each moving Part may carry its own Motion (**ADR 0124**). Any
  Motion may carry a **Ramp**: N times as fast, T seconds after the Round
  starts running, off by default (**ADR 0123**). The Round's start is
  replicated from the Countdown on, so a Ramp stays a pure function of the
  Tick.
- **Trap door: a hole on a clock.** Closed is a floor, anything else is a
  hole; a Character on it falls rather than riding it down. The clip's
  opening shudder is kept as the telegraph.
- **Fragile floor: three states, every new entry costs one.** A landing and a
  walk-on count alike, standing still does not; the third entry takes the
  floor away, and it returns after the author's delay (`0` = never). The first
  per-Segment state the Snapshot carries, predicted locally for one's own
  Character.
- **Belt: a placed Asset may arrive switched on.** A def may name a default for
  an Attachment its Segments carry, so a belt conveys the moment it is put
  down and the CONVEYOR panel retunes it. Only for an Attachment the Asset
  *is*: the machine is a belt, so it conveys. Slats are drawn, rails are solid.
- **Punching glove: a punch you can see coming.** A Part that slides on a
  clock *or* when somebody comes within reach — the author picks — re-timed so
  it crosses its 2.3 m fast enough for the ordinary Impact rule to knock down
  without a special case. Its skin is baked out at conversion.
- **Shooter: Projectile stops being deferred.** A ball every `period`,
  leaving along the barrel at the Tick it fires — so both sides derive the
  shot with no message — living a fixed time, hitting through the ordinary
  Impact rule. The population is bounded before the Round runs and publish
  refuses a Shooter that would exceed it.

## Not in this milestone

- **Debris** when a fragile tile breaks (its loose chips are authored in the
  GLB and can become bodies later without reopening ADR 0118).
- **A Shooter that aims at a Character.** It sweeps on its own clock; the
  user weighed tracking and did not take it.
- **A Character launched by a trap door**, and any Ride on one (ADR 0117).
